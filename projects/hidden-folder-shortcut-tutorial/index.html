Desktop-এ নতুন Folder তৈরি করুন

    Narration চালাতে Play চাপুন।

    গুরুত্বপূর্ণ নিরাপত্তা সতর্কতা: এই trick শুধু folder-টিকে চোখে কম দৃশ্যমান করে। এটি encryption বা password protection নয়। Hidden files settings চালু করলে folder দেখা যেতে পারে, আর অন্য কেউ path বা shortcut পেলে খুলতে পারবে। গোপনীয় ফাইলের জন্য BitLocker, VeraCrypt বা উপযুক্ত account permissions ব্যবহার করুন।
